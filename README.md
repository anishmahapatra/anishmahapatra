## Engineering principles

- Make system boundaries and failure modes visible.
- Treat reproducibility, tests, and observability as product requirements.
- Prefer simple infrastructure until scale or reliability data justifies more machinery.
- Separate measured results from proposed targets.
- Document tradeoffs so another engineer can operate the system.
