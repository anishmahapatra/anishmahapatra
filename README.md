## Engineering focus and principles

Current focus:

- Reliable model and LLM serving
- Evaluation, observability, and operational feedback loops
- Kubernetes-native delivery and platform automation
- Privacy, security, and governance for AI systems
- Data contracts for real-time and batch ML workflows

How I work:

- Make system boundaries and failure modes visible.
- Treat reproducibility, tests, and observability as product requirements.
- Prefer simple infrastructure until scale or reliability data justifies more machinery.
- Separate measured results from proposed targets.
